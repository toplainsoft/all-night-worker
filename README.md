# 올빼미방

밤샘하는 사람들이 올빼미가 되어 같이 깨어 있는 3D 온라인 작업방.
정적 페이지 하나(`index.html`)에 Supabase를 붙여서, 링크만 있으면 누구나 로그인 없이 들어와요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 방 전체 (3D 화면, 소리, 입장·퇴장, 산책, 층 구경, 의견 보내기) |
| `config.js` | Supabase 주소와 공개 키, 만석 기준 |
| `supabase/schema.sql` | 자리표·의견함 테이블과 함수. Supabase에 한 번 실행 |

`config.js`가 비어 있으면 혼자 보는 연습 모드로 열려요. 로컬에서 그냥 `index.html`을 열어봐도 돼요.

## 올리는 순서

1. **Supabase 새 프로젝트 만들기**
   지역은 **Northeast Asia (Seoul)** 로 고르세요. 올빼미 움직임은 지연이 바로 티가 나요.
2. **DB 설정**: 대시보드 > SQL Editor 에 `supabase/schema.sql` 내용을 통째로 붙여넣고 Run.
3. **Realtime 확인**: 대시보드 > Realtime > Settings 에서 "Allow public access"(공개 채널 허용)가 켜져 있어야 해요. 새 프로젝트는 기본으로 켜져 있어요.
4. **키 넣기**: Project Settings > API 에서 Project URL 과 `anon` `public` 키를 복사해 `config.js` 에 넣기.
   `service_role` 키는 절대 넣지 마세요.
5. **배포**: 이 폴더를 Vercel 에 올리면 끝. 빌드 설정 없이 정적 사이트로 올라가요.

## 무료 플랜 안에서 버티는 방법

Supabase 무료 플랜은 동시 접속 200, 초당 메시지 100, 접속자 한 명당 presence 갱신 30초에 5번까지예요.

- **만석 160마리**: 책상에 앉은 올빼미가 160마리면 다음 사람은 "지금 만석이에요" 안내를 받아요. 입구에서 구경만 하는 사람도 접속 수에 잡혀서 200보다 여유 있게 잡았어요. 바꾸려면 `schema.sql` 의 `cap` 과 `config.js` 의 `cap` 을 같이 고치고 SQL 을 다시 Run.
- **층마다 채널 따로**: 내 층(최대 12마리) 소식만 실시간으로 받아요. 건물 전체 현황(창문 불빛, 층별 인원)은 15초마다 DB 에서 가져와요.
- **상태 묶어 보내기**: 커피를 연달아 눌러도 마지막 상태만 몇 초 간격으로 보내요.
- **자리 정리**: 3분 동안 신호가 없는 자리는 자동으로 비워져요. 창을 닫으면 바로 비워져요.

## 받은 의견 보기

지금은 의견 보내기 버튼을 숨겨뒀어요. `index.html` 에서 `id="fbBtn"` 버튼의 `hidden` 을 지우면 다시 보여요.

Supabase 대시보드 > Table Editor > `owl_feedback`. 의견은 누구나 보낼 수 있지만 읽기는 대시보드에서만 돼요.

## 참고

- 무료 프로젝트는 일주일 동안 아무도 안 들어오면 잠들어요. 대시보드에서 Restore 누르면 깨어나요.
